## Single-page 

В рамках курса ProductStar создание приложение “Игральная кость”, в котором можно бросить кубик и посмотреть, что выпало. Вот критерии, которым должен соответствовать результат:

* single-page приложение, написанное на React, которое можно запустить локально с помощью “npm run start”.
* Приложение должно отображать выпавшее на кубике число с помощью локальной картинки.
* Кубик должен быть отдельным компонентом.
* В приложении должна быть кнопка, которая позволяет бросить кубик еще раз.
* Приложение должно быть стилизовано с помощью CSS.
